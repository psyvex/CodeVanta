# Ecosystems

Language and ecosystem catalogs used to identify framework, ORM, database, runtime, testing, and tooling context.

The first deep ecosystem is TypeScript/JavaScript with Node.js, NestJS, Express, Fastify, TypeORM, Prisma, Drizzle, Sequelize, MikroORM, Knex, Kysely, and common databases and tools. Additional ecosystems must follow the same extensible model.
